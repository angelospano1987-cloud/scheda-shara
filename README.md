Scheda SHARA
============

Web app statica (PWA) della scheda di allenamento: video YouTube incorporati, registro dei pesi sul dispositivo (localStorage, con esporta/importa JSON), timer di recupero.

Fonte dei dati: `Dropbox\PROGETTI CLAUDE\SHARA\SCHEDA ALLENAMENTO.docx`.

Prova in locale: `python -m http.server 8765` in questa cartella, poi http://localhost:8765 (da file:// i video YouTube non partono).
A ogni rilascio: cambiare `VERSION` in `sw.js`.
